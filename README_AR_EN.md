# أكاديمية الاتصال العالمية — الإصدار 10.1 (عميل AI بصوت مباشر)

**الأدوار ثابتة:** الذكاء الاصطناعي هو العميل ويتحدث أولًا؛ أنتِ المتدربة وموظفة خدمة العملاء. يتفاعل العميل مع كلامك صوتيًا عبر Realtime API وWebRTC.

## قبل التشغيل
- Node.js 20.6 أو أحدث (الموصى به Node 22).
- مفتاح OpenAI API جديد وسليم، بعد إلغاء أي مفتاح سبق مشاركته أو كشفه.
- تفعيل الفوترة وإتاحة Realtime API في مشروع OpenAI.
- Chrome أو Edge مع السماح بالميكروفون.

## تشغيل محلي على الكمبيوتر
1. فكّي ضغط الحزمة.
2. انسخي `.env.example` إلى ملف اسمه `.env`.
3. ضعي المفتاح الجديد في `OPENAI_API_KEY` داخل `.env` فقط. لا تضعيه في HTML ولا ترسليه في محادثة أو مستودع Git.
4. ثبّتي Node.js 22 من https://nodejs.org/ إذا لم يكن مثبتًا.
5. افتحي الطرفية داخل مجلد المشروع وشغّلي `npm install` ثم `npm start`.
6. افتحي `http://localhost:3000` في Chrome واسمحي بالميكروفون.
7. اختاري اللغة والسوق والبراند والحملة ثم اضغطي Start customer call.

## النشر على Render
1. ارفعي محتويات المجلد إلى مستودع GitHub خاص. تأكدي أن `.env` غير مرفوع؛ ملف `.gitignore` يستثنيه.
2. في Render اختاري New > Blueprint واربطِي المستودع الذي يحتوي `render.yaml`.
3. عند طلب `OPENAI_API_KEY` أضيفيه في Render Environment فقط. لا تكتبيه في ملفات المشروع.
4. ابدئي النشر وافتحي رابط HTTPS الناتج في Chrome على الهاتف، واسمحي بالميكروفون.

## الأمان
- أي مفتاح ظهر في محادثة أو صورة أو مستودع يجب إلغاؤه من منصة OpenAI وإنشاء مفتاح بديل.
- لا يمكن لهذا المشروع إلغاء مفاتيح حسابك نيابة عنك؛ لا توجد صلاحية لحساب OpenAI من داخل هذه الحزمة.
- أضيف حدًا أوليًا لمحاولات إنشاء المكالمات. قبل استخدام إنتاجي متعدد المستخدمين، أضيفي تسجيل دخول وصلاحيات ومديرًا لمعدل الطلبات مشتركًا وسجلات تدقيق وحدود إنفاق.

## الحالة والاختبارات
- فحص بناء JavaScript والخادم يتم محليًا قبل التسليم.
- لا تُعد المكالمة الحقيقية مختبرة حتى يتم ضبط مفتاح صالح على الخادم وتشغيل الموقع عبر HTTPS ثم تجربة الميكروفون والصوت على جهاز فعلي.
- حاليًا لا يحتوي المشروع على مفتاح أو بيانات دفع، ولا يرسل أي مفتاح للمتصفح.
